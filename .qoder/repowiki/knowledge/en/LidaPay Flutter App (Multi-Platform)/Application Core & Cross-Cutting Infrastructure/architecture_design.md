Organized by cross-cutting concern under `lib/core/`:
- `network/` — Dio-based `ApiClient` (with separate refresh Dio) that injects bearer tokens, redacts logs, single-flights 401 refreshes via `_refreshing`, and throws typed `ApiException`s; endpoints live in `api_endpoints.dart`, payloads in `api_payload.dart`, connectivity in `connectivity_service.dart`, and auth tokens in `token_store.dart`.
- `state/async_value_ui.dart` — a sealed `AsyncValueUi<T>` hierarchy (`LoadingUi` / `ErrorUi` / `DataUi`) used by screens to render API-bound state uniformly.
- `router/app_router.dart` — GoRouter configuration built once inside a Riverpod `Provider`, using a `StatefulShellRoute.indexedStack` with five branches (home/dashboard, services, shop, history, profile); route constants are centralized in `AppRoutes`; redirect logic gates on `hasSessionProvider` and special-cases password/payment deep links.
- `deep_links.dart` — `PaymentDeepLinkHandler` subscribes to `app_links` URIs (`lidapay://`), parks payment returns until a session exists, and forwards them to the router; integrates with the router's redirect for email password links.
- `device/device_identity.dart` — immutable `DeviceIdentity` plus `DeviceIdentityLoader` that probes platform info and persists a random UUID as `deviceId`.
- `providers/theme_provider.dart` — `ThemeModeNotifier` persisted via SharedPreferences.
- `constants/app_constants.dart` — build-time constants loaded through `String.fromEnvironment` (`API_BASE_URL`, `GOOGLE_MAPS_API_KEY`, `CHECKOUT_ALLOWED_HOSTS`).
- `utils/` and `widgets/` — shared formatters, validators, Ghana network list, URL guard, and reusable UI components (buttons, text fields, cards, skeleton loaders).
Dependency direction is inward-only: feature modules depend on core; core itself only depends on third-party packages and never on `features/` except for the router's screen imports.
