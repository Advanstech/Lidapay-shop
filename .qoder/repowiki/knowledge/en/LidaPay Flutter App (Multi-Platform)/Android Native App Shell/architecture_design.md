Standard Flutter Android project rooted at `android/` with a single Gradle subproject `:app`. The only Kotlin source is `MainActivity.kt`, which extends `FlutterFragmentActivity` to host the Flutter engine; all business logic lives in the Dart layer. Build configuration is split across `settings.gradle.kts` (plugin management, includes `flutter_tools/gradle` from the local Flutter SDK), root `build.gradle.kts` (relocates Gradle output to `../../build` so Flutter's top-level build dir is shared), and `app/build.gradle.kts` (applies `com.android.application`, `dev.flutter.flutter-gradle-plugin`, and `com.google.gms.google-services`). Release builds use minification/shrinking with ProGuard rules from `proguard-rules.pro` and symbol tables for Play Console crash deobfuscation. Signing is externalized via `key.properties` + `lidapay-upload.jks`; Google Maps API key resolution falls back through `-P` property, `GOOGLE_MAPS_API_KEY` env var, then `local.properties`. Resources under `res/` provide launcher icons, notification bitmaps, and themed launch backgrounds.
