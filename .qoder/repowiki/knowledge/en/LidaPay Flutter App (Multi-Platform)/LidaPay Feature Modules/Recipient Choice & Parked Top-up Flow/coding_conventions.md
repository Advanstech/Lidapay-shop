- Domain state is exposed through Riverpod providers defined at the top of `providers.dart`, with the repository injected via a single `recipientChoiceRepositoryProvider` rather than passed down.
- Network payloads are parsed through `payloadPool` plus `stringField`/`numberField`/`dateField` helper lists so multiple backend field names resolve to one model property.
- Long-lived background polling uses `StreamProvider.autoDispose.family` keyed by the resource id (decision id, topup order id) and stops itself when disposed or when a terminal state is reached.
- Mutable server writes go through `respondToDecision` with an idempotency key generated by `newDecisionIdempotencyKey(decisionId, choice)` so retries cannot double-submit.
- Ghana phone numbers are handled by trying both local (`0…`) and international (`233…`) shapes in `_phoneCandidates`, falling back to `RecipientEligibility.unregistered()` when neither succeeds.
- Countdown timers are scoped to the widget subtree that needs them and are cancelled as soon as the window closes or the operation becomes terminal, instead of ticking for the whole visit.
