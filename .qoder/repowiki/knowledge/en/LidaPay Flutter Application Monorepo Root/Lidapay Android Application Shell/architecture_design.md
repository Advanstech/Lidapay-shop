Standard Flutter Android project rooted at `android/` with a single Gradle subproject `:app`. The only Kotlin source is `MainActivity.kt`, which extends `io.flutter.embedding.android.FlutterFragmentActivity` to host the Flutter engine; all business logic lives in Dart. Build configuration is split across three layers: `settings.gradle.kts` loads `flutter.sdk` from `local.properties` and includes `$flutterSdkPath/packages/flutter_tools/gradle` so the Flutter Gradle plugin resolves against the local SDK; root `build.gradle.kts` relocates all Gradle output to `../../build` (so Flutter's top-level build dir is shared) and registers a `clean` task; `app/build.gradle.kts` applies `com.android.application`, `dev.flutter.flutter-gradle-plugin`, and `com.google.gms.google-services`, sets `namespace = com.advansistechnologies.lidapay_app`, and configures `compileSdk`/`ndkVersion`/`minSdk`/`targetSdk`/`versionCode`/`versionName` from the Flutter tooling. Release builds enable minification + resource shrinking with ProGuard rules from `proguard-rules.pro` and emit Play Console symbol tables via `ndk.debugSymbolLevel = SYMBOL_TABLE`. Signing is externalized through `key.properties` loaded into a `signingConfigs.release` block pointing at `lidapay-upload.jks`. Google Maps API key resolution follows an explicit priority chain — `-P GOOGLE_MAPS_API_KEY`, then `GOOGLE_MAPS_API_KEY` env var, then `local.properties` — and is injected as a manifest placeholder. Resources under `res/` provide launcher icons (`mipmap-*`), notification bitmaps (`drawable-*`), and themed launch backgrounds (`drawable-v21`).
