Each child under `lib/features/` is an independent feature module following a uniform layout: `data/` holds models + repository interfaces + mock/remote implementations, `screens/` contains route-bound UI, `widgets/` holds reusable feature components, and a top-level `providers.dart` wires Riverpod `Provider`s for repositories and `StateNotifierProvider`s for session/state. Cross-feature wiring happens via Riverpod: features depend on shared core providers (`apiClientProvider`, `tokenStoreProvider`, `deviceIdentityProvider`) from `../../core/`, and on sibling features through relative imports (e.g. `dashboard` reads `authSessionProvider` and `recipient_choice.providers`). The `shell/main_shell.dart` is the single entry point that hosts the GoRouter-based bottom-dock navigation across Home / Services / Shop / History / Profile tabs and triggers cross-feature side effects (e.g. refreshing pending recipient decisions on tab switch). Session ownership lives in `auth/providers.dart` (`AuthNotifier`), which other features consume reactively; there is no global mutable store — all inter-feature communication flows through Riverpod providers.
