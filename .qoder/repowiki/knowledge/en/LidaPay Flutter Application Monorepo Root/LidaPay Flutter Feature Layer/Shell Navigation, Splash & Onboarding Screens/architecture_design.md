Three independent feature folders under `lib/features/`, each exposing a single screen widget consumed by the app router:
- `shell/main_shell.dart` defines `MainShell` (a `ConsumerWidget` wrapping a `StatefulNavigationShell`) and a custom `MainDock` bottom bar built from a static `_tabs` tuple list of (outlined icon, rounded icon, label). It uses `go_router`'s `navigationShell.goBranch` for tab switching and conditionally hides the dock on the Shop branch (`currentIndex == 2`).
- `splash/screens/splash_screen.dart` is a `ConsumerStatefulWidget` that runs a 2.4 s `AnimationController`, restores the auth session via `authSessionProvider.notifier.restore()`, checks `hasSeenOnboarding()` and deep-link path safety, then routes to home / login / onboarding.
- `onboarding/screens/onboarding_screen.dart` renders a `PageView.builder` over three static `_Page` data entries, forces a dark cinematic look with a black background + gradient scrim, and finishes by calling `markOnboardingSeen()` followed by `context.go(AppRoutes.login)`.
All three depend only on shared `core/router/app_router.dart`, `core/widgets/brand_mark.dart`, and `core/theme/app_theme.dart`; there are no cross-dependencies between the three features.
