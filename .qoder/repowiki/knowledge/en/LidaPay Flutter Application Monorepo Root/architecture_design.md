The top-level `pubspec.yaml` is the single source of truth: it declares the Flutter SDK, Riverpod state graph, go_router navigation, Dio HTTP client, and platform plugins (Firebase, Google Maps, local_auth, geolocator) that both `lib_core` and `lib_features` consume. `android_native` and `ios_native` are native entry points embedding the same Dart codebase; `web_static` provides the Flutter web entry point plus static privacy/terms/KYC pages served alongside the app as a PWA. `tests` exercises providers and widget flows against the shared core; `api_docs` documents the backend contracts the features call; `tooling` ships auxiliary scripts outside the Flutter build. Cross-child wiring happens at the top level via asset declarations in `pubspec.yaml` (`assets/images/`, `assets/icons/`, Plus Jakarta Sans fonts) consumed by all UI layers, and the version string (`1.1.3+34`) is incremented before each Play release per README instructions.
